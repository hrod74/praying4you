# components/

Reusable UI components for feature screens. **Empty in Phase A** (foundation only) —
the placeholder screens use inline markup so each route stays self-contained and
obviously a placeholder.

Planned (later phases):

- `PrayerCard.tsx` — feed card (Phase C).
- `PrayedButton.tsx` — "I prayed for this" button + count (Phase E).
- `AnonymousToggle.tsx` — name vs. Anonymous switch (Phase D).
- `ReportSheet.tsx` — report reason picker (Phase G).
- `EmptyState.tsx` — friendly empty states (Phase C+).
