# context/

React Context providers for app-wide state. **Empty in Phase A** (foundation only).

Planned (later phases):

- `AuthContext.tsx` — local profile (name, email) + simulated signed-in/out state (Phase B).
- `PrayerContext.tsx` — in-memory prayer list, the set of requests the user has prayed
  for, and actions (submit, pray, report) (Phases C–G).

Lightweight Context + hooks only — no Redux at this scale.
